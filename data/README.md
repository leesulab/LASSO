# Donnees

Ce dossier est reserve aux donnees locales de travail.

Organisation proposee :

- `raw/` : donnees brutes ou exports originaux.
- `parquet/` : fichiers Parquet utilises pour les tests et l'application.
- `processed/` : donnees transformees, agregees ou nettoyees.

Les donnees volumineuses ne doivent pas etre versionnees directement dans Git. Garder ici seulement les fichiers necessaires au travail local.
